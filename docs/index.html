The honest split

What this is — and what it isn't, yet.

An ESP32 streams WiFi Channel State Information to a Jetson Nano, which runs a self-healing pipeline through the night. That part works. The part that started this project — catching muscle guarding before pain registers consciously — doesn't, yet.

Channel A — Working

Gross body movement and repositioning, detected reliably through the night. Two live dashboards. A deployed, self-healing edge pipeline running on real hardware, not simulation.

Channel B — Not yet

Pre-onset micro-muscular guarding — the reflexive tensing that may precede conscious pain. Several orders of magnitude smaller than what this hardware currently resolves. The real open problem.

Field log

What actually happened, in order.

v0

RSSI: giving shadows, not shapes Dead end

A single signal-strength number per second couldn't tell a person shifting in bed from someone walking through the next room. Abandoned.

v1

Switch to CSI Fix

52 subcarriers of amplitude and phase per packet gave real spatial resolution. Gross movement became reliably detectable.

—

Posture classifier collapses on real hardware Finding

86% in simulation, incoherent in deployment. Fixed room geometry made upright/slouched/lying nearly indistinguishable. Reported as-is, not hidden.

—

Breathing rate was silently wrong Bug

A hardcoded 100Hz sample rate didn't match the real bursty ~26–34 pkt/s from the ESP32. Fixed by computing rate from real timestamps.

tonight

Independent validation, on real data Result

A second, separately-written implementation of the breathing-rate logic was run against real recorded packets on the actual deployment hardware — and agreed with the live pipeline.

The real problem

The gap that's still open.

Gross repositioning produces amplitude changes clearly visible above ambient noise. The micro-muscular guarding I actually set out to catch is, by rough estimate, several orders of magnitude smaller — likely below this system's current noise floor. That gap hasn't been formally measured yet. That's the next step, not a footnote.

On ground truth: the obvious next move would be a surface EMG reference to validate what the WiFi system detects. I'm not doing that. My mother's comfort takes priority over data collection, and I'd rather report an honest limitation than push past what's appropriate for the person this project exists to help.
